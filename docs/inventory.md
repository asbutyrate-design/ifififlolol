## 4. ТЕХНИЧЕСКИЕ ЗАМЕЧАНИЯ

### Кодировка и формат

- **Формат файлов:** TXT
- **Кодировка:** UTF-8 (прочитано корректно)
- **Перевод строк:** Windows (CRLF, `\r\n`), обнаружено при проверке. Нормально для .txt, но требует внимания при преобразовании в Markdown.
- **Проблем с кодировкой:** не выявлено

### Структура содержимого

Каждый файл содержит несколько проектов, разделённых по следующей примерной структуре:

1. **Заголовок проекта:** "The name of the scientific project:" или "Название научного проекта:"
2. **Краткое описание:** 1–3 предложения
3. **Команда проекта:** список авторов с должностями и инициалами
4. **Описание:** полный текст проекта (1–3 абзаца)
5. **Публикации:** список с ФИО авторов, названиями, годами, DOI/URL (если есть)
6. **Конференции и события:** список выступлений и презентаций

### Потенциальные проблемы при извлечении

1. **Непоследовательная структура:** не все проекты имеют все разделы. Например, ФП (англ.) очень краток.
2. **Смешанные таблицы:** в некоторых файлах авторы и публикации оформлены как таблицы; при конвертации в Markdown требуется внимание.
3. **Форматирование списков:** используются маркеры типа `-`, `•`, цифры; нужно привести к единому стилю Markdown.
4. **Перекрёстные ссылки между языками:** в русском и английском файлах один и тот же проект может быть озаглавлен по-разному, что затруднит автоматическую привязку.
