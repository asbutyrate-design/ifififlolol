### Маркеры, реально встречающиеся в файлах

Русские файлы — единообразно:
`Название научного проекта:` (в ФЕ_рус есть вариант капсом `НАЗВАНИЕ НАУЧНОГО ПРОЕКТА:`).

Английские файлы — **пять разных формулировок**:

| Файл | Маркер |
|---|---|
| АКФХ_анг.txt | `The name of the scientific project:` |
| БТ_анг.txt | `Name of the research project:` |
| ОЭФ_анг.txt | `Research Project Title:` |
| ФАРМАК_анг.txt | смесь: `Название научного проекта:` ×1 (по-русски!), `The name of the project:` ×1, `The name of the research project:` ×3 |
| ФАРМАЦ_анг.txt | `Title of the research project:` |
| ФЕ_анг.txt | смесь: `The name of the scientific project:`, `NAME OF THE SCIENTIFIC PROJECT:`, `Research Project Title:`, `Project Title:` ×2 |
| ФП_анг.txt | `Research Project Title` (без двоеточия) |
| ФТ_анг.txt | `Name of the scientific project:` |
| ФХ_анг.txt | `Project Title:` |

Это главная техническая причина, по которой наивный парсер «не находил»
английские проекты. Парсер должен принимать все пять формулировок и не
зависеть от регистра и наличия двоеточия.

### Порядок проектов в ru- и en-файлах не совпадает

Пары нельзя брать «по индексу». Пример АФКХ:

| RU | EN |
|---|---|
| 1. Качество распыления фармацевтических аэрозолей и спреев | 3. The quality of spraying pharmaceutical aerosols and sprays |
| 2. Повышение биодоступности малорастворимых ЛС – твёрдые дисперсии | 2. Improving the bioavailability of poorly soluble medicinal products – solid dispersions |
| 3. Исследование адсорбционной способности аптечных энтеросорбентов | 1. Study of the adsorption capacity of pharmaceutical enterosorbents |

Сопоставление ru↔en делается **по смыслу**, вручную, и результат
фиксируется в `slug` на ЭТАПЕ 2. Для ОЭФ расхождение ещё сильнее
(R2 ↔ E5, R3 ↔ E2, R4 ↔ E3, R5 ↔ E4).

## 4. ЯВНЫЕ ПРОБЛЕМЫ

### Критические

1. **Порядок проектов ru ≠ en** — сопоставление только вручную (см. §3).
2. **ФАРМАК_анг.txt содержит русский маркер** `Название научного проекта:`
   в первом проекте, дальше — английские. Файл объявлен английским;
   внутри одного файла два набора маркеров. Текст при этом английский,
   так что это опечатка шапки, а не смешение языков.

### Важные

3. **Пять разных формулировок заголовочного маркера** в английских файлах (§1).
4. **Разный формат кавычек:** `«…»`, `"…"`, `“…”`, `'…'`, а также
   заголовок без кавычек отдельной строкой (БТ, ФЕ, ФТ, ФХ_анг).
5. **CRLF во всех файлах кроме `ФХ_анг.txt`** (LF). `.gitattributes`
   нормализует при коммите — файлы в репозитории уже в LF.
6. **Форматы описаний внутри блоков сильно разные**: у БТ есть
   «Project goal / Key objectives», у ОЭФ — «Project Aim / Key Objectives»,
   у ФАРМАК — «Objective / Key points», у ряда блоков — только абзац
   текста. Единый парсер секций придётся писать терпимым к вариантам.
7. **Фотографии авторов отсутствуют** — ни путей, ни имён файлов.

### Мелочи

8. В `БТ_анг.txt` есть служебные символы `\u0335` (COMBINING) перед
   `Key objectives:` — мусор форматирования, чистить на ЭТАПЕ 1.
9. В `ФП_анг.txt` встречаются русские строки **внутри** английского текста:
   `Описание проекта_QbD.docx` — это имя приложенного файла, а не текст.
   На публикуемую страницу не пойдёт, но факт вынести в отчёт.
10. В `АФКХ_анг.txt` в списке публикаций есть русскоязычные позиции
    (Малышева Е., Жукова А. …) — это нормально, публикация на русском,
    не смешение языков файла.
