# Таксономия и ресурсы перспективных для использования в медицине растений

## Команда проекта

заведующий кафедрой фармацевтического естествознания, д.фарм.н. Луферов А.Н., аспирантка Мельник А.А., студентка Тинкт А.В.

## Описание проекта

## Цель проекта

Изучение и анализ таксономического состава, распространения и продуктивности растений, повышения эффективности использования их ресурсов для практической фармации.

## Ключевые задачи

- Исследование биоразнообразия семенных растений для выявления таксономически значимых признаков;
- Определение видового состава и систематического положения семенных растений; составление ключей для их идентификации;
- Изучение географических особенностей видов; составление точечных карт их ареалов;
- Проведение оценки перспективных направлений использования семенных растений в медицинской практике.
