# Бесклеточные системы трансляции для биоинженерии и синтетической биологии.

## Команда проекта

К.б.н. Хабибуллина Н.Ф. Студенты: Дзагаштова Д., Однолько П., Олейник Н., Паламарчук Д.

## Проект выполняется совместно с

МГУ имени М.В. Ломоносова, Институт биоорганической химии им. академиков М.М. Шемякина и Ю.А. Овчинникова РАН, НИИ СБМ Роспотребнадзора.

## Описание проекта

Проект направлен на биоинженерные разработки и оптимизацию бесклеточных систем экспрессии для производства белковых продуктов. Методами генной инженерии, биоинженерии и синтетической биологии исследуются возможности бесклеточных систем трансляции в биотехнологии и производстве небелковых продуктов.

## Цель проекта

Биоинженерная разработка и оптимизация бесклеточных систем экспрессии для эффективного производства белковых продуктов и небелковых соединений.

## Ключевые задачи

1. Разработка и оптимизация бесклеточных систем экспрессии для производства целевых белковых продуктов.
2. Применение методов генной инженерии для совершенствования компонентов бесклеточных систем трансляции.
3. Исследование возможностей бесклеточных систем трансляции в биотехнологии.
4. Изучение потенциала бесклеточных систем для производства небелковых продуктов.
5. Интеграция подходов синтетической биологии для расширения функциональности бесклеточных систем экспрессии.
