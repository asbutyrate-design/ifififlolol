# Разработка цифровых платформ для исследований и разработки лекарственных средств

## Команда проекта

к.х.н. Апполонова С.А., аспиранты Резванов П.А., Болдин А.А.

## Описание проекта

## Цель проекта

Разработка цифровых платформ: управления доклиническими испытаниями, системы прогнозирования органотоксичности, исследований биоэквивалентности лекарственных препаратов и системы мониторинга фармакотерапии.

## Ключевые задачи

-Метаболомное исследование органотоксичности лекарственных препаратов на зебрафиш в качестве модельного организма;
-Исследование изменения метаболомного профиля плазмы крови у пациентов;
-Создание баз данных для определения органотоксичности с помощью метаболомных биомаркеров различных лекарственных средств;
-Разработка веб-приложений для проведения фармакокинетического анализа в доклинических исследованиях лекарственных препаратов;
